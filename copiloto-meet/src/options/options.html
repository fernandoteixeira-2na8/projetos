Copiloto de Reuniao

Tudo fica no storage local deste navegador. Nada e sincronizado com a conta Google.

Acesso a API

A chave vai do seu navegador direto para a API. Isso serve para uso proprio. Para distribuir a extensao para o time, use o modo backend — senao qualquer pessoa com a extensao instalada le a chave.

O backend precisa espelhar a rota /v1/messages da API Anthropic.

Contexto

Serve para separar a sua fala da do cliente e medir o monologo.

E daqui que sai a resposta dos cards. Sem isso, o copiloto so sabe dizer que vai confirmar depois.

Quando interromper

Subir a confianca e o intervalo custa menos cards, mas protege sua atencao — que e o recurso escasso aqui, nao o token.

Privacidade

A deteccao de apresentacao e heuristica. A protecao que realmente funciona e compartilhar uma janela ou aba especifica, nunca a tela inteira.
